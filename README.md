# PDF Receipt Maker 🧾

CLI-скрипт на Python: читает CSV/JSON с данными заказов, подставляет их в HTML-шаблон
и генерирует PDF-чек (счёт, накладную) с автоматическим открытием в системной программе.

## Возможности

- 📂 Автоматическое обнаружение файлов `*.csv` и `*.json` в папке `data/`
- 🎨 Автоматическое обнаружение `*.html` шаблонов в папке `templates/`
- 🖥️ Интерактивное меню в консоли (выбор файла → шаблона → конкретного чека по `invoice_id`)
- 🇷🇺 Корректное отображение кириллицы (DejaVu Sans / Roboto)
- 📄 Генерация PDF через WeasyPrint
- 🚀 Автоматическое открытие готового PDF (macOS / Windows / Linux)
- 📁 Все PDF складываются в `output/`
- 🧩 Поддержка двух форматов JSON:
  - плоский список записей
  - список чеков с вложенным массивом `items`

## Установка (macOS)

bash
# 1. Системные библиотеки для WeasyPrint
brew install pango libffi

# 2. Виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 3. Python-зависимости
pip install -r requirements.txt
Если WeasyPrint не находит libgobject-2.0-0 — добавьте в ~/.zshrc:

bash
export DYLD_LIBRARY_PATH="$(brew --prefix)/lib:$DYLD_LIBRARY_PATH"
Использование
bash
python pdf_generator.py
Далее следуйте подсказкам в консоли: выберите файл данных → шаблон → invoice_id.
Готовый PDF появится в output/ и откроется автоматически.

📌 Промпт, использованный для генерации

Напиши Python-скрипт, который:

1) Читает все доступные CSV и JSON файлы в директории /data
   - CSV парсит через pandas
   - JSON парсит стандартной библиотекой json
2) Читает все HTML-шаблоны из директории /templates
3) При запуске выводит список:
   - доступных файлов с данными
   - доступных шаблонов
4) Даёт пользователю выбрать (через input) один файл данных и один HTML-шаблон
5) Выводит список доступных чеков (по invoice_id) из выбранного файла
6) Пользователь выбирает конкретный invoice_id — по нему генерируется PDF:
   - данные подставляются в HTML-шаблон (плейсхолдеры {{ invoice_id }},
     {{ customer_name }}, {{ date }}, {{ rows }}, {{ total }})
   - PDF сохраняется в директорию /output
7) После генерации автоматически открывает PDF в системной программе

Требования:
- WeasyPrint для генерации PDF
- Поддержка кириллицы (DejaVu Sans или Roboto через CSS)
- Работает на Windows и macOS (открытие: open / xdg-open / os.startfile)
- Аккуратное консольное меню с нумерацией
- Скрипт должен сам создавать папки data/templates/output, если их нет
- JSON может быть двух видов: плоский список записей или список чеков с items
- Используй только str.replace, без Jinja2
